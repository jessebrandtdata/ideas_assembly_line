# Bill Delay Tracker prototype

See [`../prototype-bill-delay-tracker.md`](../prototype-bill-delay-tracker.md) for what this is and how to run it.

`collect.py` → `data/*.csv` → `delays.py` → `data/stats.json` + `data/delays.json` (+ `data/delays.js`, the same document as a script) → `dashboard/`.
`tests/fixture/` runs `delays.py` on a bundled sample with no network.
`dashboard/index.html` is the view of the data. Open it straight from disk, no server needed: browsers block `fetch()` of local files on `file://` pages, so `delays.py` also writes the data as a script, `data/delays.js`, and the page loads it with a plain `<script>` tag (the d3 library and the webfont still come from the network). Serving the prototype folder (`python3 -m http.server`, open `/dashboard/`) works too. Page-wide filters sit in the top row: stage (default all stages), bill type, an introduced-from/to date range (two day-level date pickers bounded by the first and last text date in the data; empty = open side; inclusive, on the text version's issue date) and a "Clear date filters" button; a monthly stacked-share chart (summarized vs waiting, by month the text was issued; no lag-over-time lines, which right-censoring would make misleading) shades the months the range touches; beneath the histogram are its own controls, a bin-width slider (7 to 90 days) and a checkbox to include bills still waiting for a summary. The stage select also scopes the "pages of bill text" card and both lines of the cumulative pages chart to that stage's text versions (all stages: every edition, including unmapped ones); the "reported by committee" card ignores it. Two top-10 tables close the page, both following the page filters and ties broken by bill number: "Longest lags" (summarized records, by lag in days) and "Oldest bills still waiting" (records with no summary, by days from text date to the data's as-of date); each bill is a link to its congress.gov page.

## Exports

Each of the four charts has "Download PNG" and "Download SVG" buttons above it, and each of the two tables has a "Download CSV" button in its heading. The files follow the current stage, bill type and date filters and are named `bill-delay-<figure>-<stage>-<type>[-<from>_<to>]-<as_of>`, for example `bill-delay-histogram-all-all-2026-10-15.png`. The PNG is a fixed-size export: twice the chart's design size (the 920 px wide viewBox plus the title band), the same file whatever the window width. Because an SVG loaded as an image cannot fetch the Google webfont, PNGs use the system fallback font. The CSVs hold every row of the filtered table in its sort order, not only the ten shown (longest lags: all summarized text versions; oldest waiting: all staged versions still without a summary).
